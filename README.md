# ECOAST — Engineering Computing Academy of Science and Technology

A static promotional website for ECOAST featuring modern design with animations, interactive elements, and responsive layout.

## Features

- **Hero Cover Page** — Animated particle background, gradient text, floating shapes, and live stat counters
- **About Section** — Mission statement, core values, and institutional highlights
- **Programs Section** — Academic program cards with featured highlighting
- **Campus Section** — Innovation-focused campus showcase
- **Events Section** — Upcoming hackathons, tech talks, and workshops
- **Testimonials** — Student and alumni voices
- **Contact Form** — Inquiry form with toast notifications
- **Responsive Design** — Fully mobile-friendly with hamburger menu

## Tech Stack

- HTML5
- CSS3 (custom properties, grid, flexbox, animations)
- Vanilla JavaScript (IntersectionObserver, smooth scroll, particle system)
- Font Awesome 6.5 icons
- Google Fonts (Inter + Space Grotesk)
